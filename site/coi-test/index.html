単スレッド wasm 検証（COOP/COEP なし）

ほかのページは COOP / COEP というヘッダをサーバから配って cross-origin isolated な状態を作っています。変換エンジン（Mozc の WebAssembly ビルド）が スレッドを使う＝SharedArrayBuffer を要求するためです。

この制約はホスト側の権限が要るので、ヘッダを設定できない場所には置けません。そこで スレッドを使わないビルドを用意し、このページだけ COOP/COEP を意図的に外して 動くかどうかを確かめています。ここで日本語が打てれば、ヘッダなしでも成立するという実証になります。

期待値: crossOriginIsolated が false（＝ COOP/COEP が無い状態）で、 それでも下のエディタで変換ができる。SharedArrayBuffer の有無はブラウザによって違います （Chrome は COI でなくても定義自体は残っていることがあります）。判定は「COI が false」かつ 「変換が動く」で見てください。

OS 側の日本語 IME はオフ（英数直接入力）にして、ふつうにローマ字で打鍵してください。 学習・ユーザー辞書・テキストはラボ内の各実験ページと共有です（ここで打った内容もほかのページに出ます）。

  • Space = 変換 / 次候補、Enter = 確定、Esc = 戻す、数字 1-9 = 直接選択
  • ←→ = 文節移動、Shift+←→ = 文節伸縮、Ctrl+BS = 確定取り消し（学習も巻き戻し）
  • 確定済みテキストを選択して 変換キー / Ctrl+/ = 再変換
  • 見るべきところ: 変換の精度と速さが、ほかのページと変わらないこと。 起動（辞書ロード後の初期化）はむしろ速くなっているはずですが、辞書 18.9MB の ダウンロードが支配的なので体感差はほとんどありません
