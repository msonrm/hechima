環境診断（COOP/COEP なしで動くこと）

以前この変換エンジン（Mozc の WebAssembly ビルド）はスレッドを使っていて、 SharedArrayBuffer のために COOP / COEP というヘッダを サーバから配る必要がありました。ホスト側の権限が要るので、ヘッダを設定できない場所には 置けないという制約でした。

2026 年 7 月に、スレッドを使わないビルドへ移行してこの制約をなくしました。 いまラボ全体がヘッダなしで動いています。このページは、その状態を実機で確認するための 診断と、ほかのサイトへ組み込むときの参照用に残してあります。

期待値: crossOriginIsolated が false（＝ COOP/COEP が無い状態）で、 それでも下のエディタで変換ができる。SharedArrayBuffer の有無はブラウザや遷移の タイミングで変わります（Safari は COI のページと往復すると定義が残ることがあります）が、 いまの変換エンジンはこれを使わないので影響はありません。

OS 側の日本語 IME はオフ（英数直接入力）にして、ふつうにローマ字で打鍵してください。 学習・ユーザー辞書・テキストはラボ内の各実験ページと共有です（ここで打った内容もほかのページに出ます）。

  • Space = 変換 / 次候補、Enter = 確定、Esc = 戻す、数字 1-9 = 直接選択
  • ←→ = 文節移動、Shift+←→ = 文節伸縮、Ctrl+BS = 確定取り消し（学習も巻き戻し）
  • 確定済みテキストを選択して 変換キー / Ctrl+/ = 再変換
  • 見るべきところ: 変換の精度と速さが、ほかのページと変わらないこと。 起動（辞書ロード後の初期化）はむしろ速くなっているはずですが、辞書 18.9MB の ダウンロードが支配的なので体感差はほとんどありません
