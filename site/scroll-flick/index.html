動くフリック入力のご提案

フリック入力は、指を動かして文字を選ぶ入力方式です。しかしこの「指を動かす」という動作は、 親指に少なからぬ無理を強いています。そこで発想を逆転しました。指ではなく、盤面のほうを動かします。

キーボードの中央 3 列は常にゆっくりスクロールしています。画面を適切に押して離すだけでフリック入力ができます。たとえば「か」を押したまま盤面が上へ流れれば、 指は相対的に下へ動いたことになり、「こ」が入力されます。盤面は端でつながっているので、スクロールは止まりません。

さらに、目をつぶって適当に押して離すと、ランダムな文字が入力できます。 お告げ（占い）や、インスピレーションを得る用途にもご活用いただけます。

下のキーボードで試せます（PC ではマウスでも動きます）。

  • 盤面の動き: 3 秒静止 → 右へ 3 秒 → 3 秒静止 → 下へ 4 秒 → 3 秒静止 → 左へ 3 秒 → 3 秒静止 → 上へ 4 秒、の繰り返し。 1 マス/秒で動くので、横は 3 秒・縦は 4 秒で元の位置に戻ります
  • すばやく押して離す = ふつうのタップ（中央の文字）。盤面が動いていても、押している間のずれが小さければタップです
  • 盤面が右へ動いている間に押す = 指から見て盤面が左へ動くので「左フリック」。 同じように、下へ動いている間は「上」、左なら「右」、上なら「下」のフリックになります
  • 押している間、いま離したら入力される文字が上端に出ます。押したキーは盤面と一緒に流れていきます
  • 変換・確定・候補の扱いは通常のフリック入力と同じです
